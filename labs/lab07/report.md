# Лабораторная работа №7
## Анализ файловой системы Linux. Команды для работы с файлами и каталогами

### 1. Цель работы
Ознакомление с файловой системой Linux, её структурой, именами и содержимым каталогов. Приобретение практических навыков по применению команд для работы с файлами и каталогами, по управлению процессами, по проверке использования диска и обслуживанию файловой системы.

### 2. Задание
1. Выполнить упражнения по работе с командами для работы с файлами и каталогами (`touch`, `cp`, `mv`, `mkdir`, `rm`).
2. Изучить механизм прав доступа и изменения прав (`chmod`).
3. Выполнить задания для самостоятельного решения.
4. Просмотреть примонтированные файловые системы (`mount`, `/etc/fstab`, `df`, `fsck`).

### 3. Теоретическое введение

**Основные команды для работы с файлами и каталогами:**

| Команда | Описание |
|---------|----------|
| `touch` | Создание пустого файла |
| `cp` | Копирование файлов и каталогов |
| `mv` | Перемещение и переименование файлов и каталогов |
| `mkdir` | Создание каталогов |
| `rm` | Удаление файлов и каталогов |
| `chmod` | Изменение прав доступа |
| `mount` | Просмотр примонтированных файловых систем |
| `df` | Проверка использования диска |
| `fsck` | Проверка целостности файловой системы |

**Права доступа:**

| Право | Обозначение | Для файла | Для каталога |
|-------|-------------|-----------|--------------|
| Чтение | `r` | Разрешены просмотр и копирование | Разрешён просмотр списка файлов |
| Запись | `w` | Разрешены изменение и переименование | Разрешены создание и удаление файлов |
| Выполнение | `x` | Разрешено выполнение | Разрешён доступ в каталог |

**Формы записи прав доступа:**

| Двоичная | Восьмеричная | Символьная |
|----------|--------------|------------|
| 111 | 7 | rwx |
| 110 | 6 | rw- |
| 101 | 5 | r-x |
| 100 | 4 | r-- |
| 011 | 3 | -wx |
| 010 | 2 | -w- |
| 001 | 1 | --x |
| 000 | 0 | --- |
