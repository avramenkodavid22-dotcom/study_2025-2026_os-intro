# Лабораторная работа №4
## Продвинутое использование git

### 1. Цель работы
Получение навыков правильной работы с репозиториями git, освоение модели ветвления Gitflow, семантического версионирования и стандарта оформления коммитов (Conventional Commits).

### 2. Задание
1. Создать тестовый репозиторий `git-extended`.
2. Настроить интеграцию с GitHub.
3. Внедрить соглашение о Conventional Commits.
4. Освоить работу с Gitflow (создание веток `feature`, `release`, `hotfix`).
5. Создать два релиза (`v1.0.0` и `v1.2.3`) и опубликовать их на GitHub.
