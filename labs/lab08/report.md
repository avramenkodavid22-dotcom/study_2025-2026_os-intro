# Лабораторная работа №8
## Поиск файлов. Перенаправление ввода-вывода. Просмотр запущенных процессов

### 1. Цель работы
Ознакомление с инструментами поиска файлов и фильтрации текстовых данных. Приобретение практических навыков: по управлению процессами (и заданиями), по проверке использования диска и обслуживанию файловых систем.

### 2. Задание
1. Записать в файл file.txt названия файлов из каталога `/etc` и домашнего каталога.
2. Найти файлы с расширением `.conf` и записать их в `conf.txt`.
3. Найти файлы в домашнем каталоге, начинающиеся с символа `c`.
4. Вывести постранично файлы из `/etc`, начинающиеся с `h`.
5. Запустить процесс в фоновом режиме для записи файлов, начинающихся с `log`.
6. Запустить `gedit` в фоновом режиме и завершить его с помощью `kill`.
7. Выполнить команды `df` и `du`.
8. Найти все каталоги в домашнем каталоге.

### 3. Теоретическое введение

**Перенаправление ввода-вывода:**

| Символ | Описание |
|--------|----------|
| `>` | Перенаправление stdout в файл (перезапись) |
| `>>` | Перенаправление stdout в файл (добавление) |
| `2>` | Перенаправление stderr в файл |
| `&>` | Перенаправление stdout и stderr в файл |
| `\|` | Конвейер (pipe) — передача вывода одной команды на ввод другой |

**Основные команды:**

| Команда | Описание |
|---------|----------|
| `find` | Поиск файлов и каталогов |
| `grep` | Поиск строк в тексте |
| `df` | Проверка использования диска |
| `du` | Проверка размера файлов и каталогов |
| `ps` | Просмотр запущенных процессов |
| `jobs` | Просмотр фоновых задач |
| `kill` | Завершение процессов |
| `less` | Постраничный просмотр текста |
