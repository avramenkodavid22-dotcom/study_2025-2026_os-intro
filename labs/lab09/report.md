# Лабораторная работа №9
## Командная оболочка Midnight Commander

### 1. Цель работы
Освоение основных возможностей командной оболочки Midnight Commander. Приобретение навыков практической работы по просмотру каталогов и файлов; манипуляций с ними.

### 2. Задание
1. Создайте текстовой файл text.txt.
2. Откройте этот файл с помощью встроенного в mc редактора.
3. Вставьте в открытый файл небольшой фрагмент текста, скопированный из любого другого файла или Интернета.
4. Проделайте с текстом следующие манипуляции, используя горячие клавиши:
    - 4.1. Удалите строку текста.
    - 4.2. Выделите фрагмент текста и скопируйте его на новую строку.
    - 4.3. Выделите фрагмент текста и перенесите его на новую строку.
    - 4.4. Сохраните файл.
    - 4.5. Отмените последнее действие.
    - 4.6. Перейдите в конец файла (нажав комбинацию клавиш) и напишите некоторый текст.
    - 4.7. Перейдите в начало файла (нажав комбинацию клавиш) и напишите некоторый текст.
    - 4.8. Сохраните и закройте файл.
5. Откройте файл с исходным текстом на некотором языке программирования (например С или Java).
6. Используя меню редактора, включите подсветку синтаксиса, если она не включена, или выключите, если она включена.

Через правую панель было открыто **Древо каталогов** (меню Правая панель → Дерево). В режиме Дерево на панели отображается структура дерева каталогов.

- Удаление строки текста (Ctrl+Y).

- Отмена последнего действия (Ctrl+U).
- Переход в конец файла и добавление текста (Ctrl+End).
- Переход в начало файла и добавление текста (Ctrl+Home).
- Сохранение и закрытие файла (F2, затем F10).

### 4. Контрольные вопросы

**1. Какие режимы работы существуют в mc? Охарактеризуйте их.**

Панели могут быть переведены в один из двух режимов: **Информация** или **Дерево**. В режиме **Информация** на панель выводятся сведения о файле и текущей файловой системе. В режиме **Дерево** на одной из панелей выводится структура дерева каталогов.

**2. Какие операции с файлами можно выполнить как с помощью команд shell, так и с помощью меню (комбинаций клавиш) mc? Приведите несколько примеров.**

Большинство операций с файлами можно выполнить как через команды shell, так и через меню mc:
- Копирование: `cp` в shell, **F5** в mc.
- Перемещение/переименование: `mv` в shell, **F6** в mc.
- Удаление: `rm` в shell, **F8** в mc.
- Создание каталога: `mkdir` в shell, **F7** в mc.
- Просмотр файла: `cat`/`less` в shell, **F3** в mc.

**3. Опишите структуру меню левой (или правой) панели mc, дайте характеристику командам.**

Меню панели содержит следующие пункты:
- **Формат списка**: позволяет выбрать формат отображения файлов (Стандартный, Ускоренный, Расширенный, Определённый пользователем).
- **Способ сортировки**: позволяет сортировать файлы по имени, расширению, времени изменения, размеру и т.д.
- **Фильтр**: позволяет отображать только файлы, соответствующие шаблону.
- **Информация**: переключает панель в режим отображения информации о текущем файле.
- **Дерево**: переключает панель в режим отображения дерева каталогов.
- **Быстрый просмотр**: включает режим быстрого просмотра содержимого файла.

**4. Опишите структуру меню Файл mc, дайте характеристику командам.**

Меню **Файл** содержит команды для работы с файлами:
- **Просмотр (F3)**: просмотр содержимого текущего файла.
- **Правка (F4)**: открытие файла для редактирования.
- **Копирование (F5)**: копирование файлов и каталогов.
- **Переименование (F6)**: переименование или перемещение файлов/каталогов.
- **Создание каталога (F7)**: создание нового каталога.
- **Удалить (F8)**: удаление файлов/каталогов.
- **Права доступа (Ctrl+X C)**: изменение прав доступа к файлу/каталогу.
- **Владелец/группа (Ctrl+X O)**: изменение владельца и группы.
- **Жёсткая ссылка (Ctrl+X L)**: создание жёсткой ссылки.
- **Символическая ссылка (Ctrl+X S)**: создание символической ссылки.
- **Выход (F10)**: завершение работы mc.

**5. Опишите структуру меню Команда mc, дайте характеристику командам.**

Меню **Команда** содержит общие команды:
- **Дерево каталогов**: отображение структуры каталогов.
- **Поиск файла**: поиск файлов по заданным параметрам.
- **Переставить панели**: меняет местами левую и правую панели.
- **Сравнить каталоги (Ctrl+X D)**: сравнение содержимого двух каталогов.
- **Размеры каталогов**: отображение размера и времени изменения каталогов.
- **История командной строки**: список ранее выполненных команд.
- **Каталоги быстрого доступа (Ctrl+\)**: быстрая смена текущего каталога.
- **Восстановление файлов**: восстановление файлов на ext2/ext3.
- **Редактировать файл расширений**: настройка действий для файлов с определёнными расширениями.
- **Редактировать файл меню**: редактирование контекстного меню пользователя.
- **Редактировать файл расцветки имён**: настройка цветовой схемы для имён файлов.

**6. Опишите структуру меню Настройки mc, дайте характеристику командам.**

Меню **Настройки** содержит опции по внешнему виду и функциональности mc:
- **Конфигурация**: настройка работы с панелями.
- **Внешний вид и Настройки панелей**: настройка отображаемых элементов и цветовой схемы.
- **Биты символов**: формат обработки информации локальным терминалом.
- **Подтверждение**: настройка подтверждения при удалении, перезаписи и выходе.
- **Распознание клавиш**: тестирование функциональных клавиш.
- **Виртуальные ФС**: настройка виртуальной файловой системы.

**7. Назовите и дайте характеристику встроенным командам mc.**

Основные встроенные команды mc:
- **F1**: вызов справки.
- **F2**: вызов пользовательского меню.
- **F3**: просмотр файла.
- **F4**: редактирование файла.
- **F5**: копирование.
- **F6**: перемещение/переименование.
- **F7**: создание каталога.
- **F8**: удаление.
- **F9**: вызов меню.
- **F10**: выход из mc.

**8. Назовите и дайте характеристику командам встроенного редактора mc.**

Основные команды встроенного редактора mc:
- **Ctrl+Y**: удалить строку.
- **Ctrl+U**: отмена последнего действия.
- **Ctrl+Ins**: копировать выделенный фрагмент.
- **Shift+Ins**: вставить фрагмент.
- **Ctrl+X**: вырезать фрагмент.
- **F2**: сохранить файл.
- **F4**: замена текста.
- **F7**: поиск текста.
- **F10**: выход из редактора.
- **Ctrl+Home**: переход в начало файла.
- **Ctrl+End**: переход в конец файла.

**9. Дайте характеристику средствам mc, которые позволяют создавать меню, определяемое пользователем.**

Пользователь может создавать собственное меню, редактируя файл `~/.mc.menu`. Для этого используется пункт меню **Команда** → **Редактировать файл меню**. В этом файле можно определять команды, которые будут доступны по клавише **F2**. Формат записи позволяет создавать подменю и назначать действия для различных типов файлов.

**10. Дайте характеристику средствам mc, которые позволяют выполнять действия, определяемые пользователем, над текущим файлом.**

Панель в Midnight Commander отображает список файлов текущего каталога. Абсолютный путь к этому каталогу отображается в заголовке панели. У активной панели заголовок и одна из её строк подсвечиваются. Управление панелями осуществляется с помощью комбинаций клавиш или пунктов меню. Пользователь может выполнять действия над текущим файлом через меню **Файл** или с помощью функциональных клавиш (F3–F8).
